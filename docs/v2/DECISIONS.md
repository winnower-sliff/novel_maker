> 本文是 v2 全部产品决策的权威记录：六轮 grillme 盘问共识（52 项）+ REQUIREMENTS.md 草案融合拍板（24 项）。

> 日期：2026-11-05。分支：feat/v2-rebuild。

## 0. 产品一句话

**Tailscale 局域网内的私人小说工坊**：电脑跑极简托盘服务端，手机 APP 是唯一入口。
「写小说」变成「做选择」——agent 当导演给走向，作者只选。无桌面应用、无浏览器版、无系统通知。

## 1. 总体架构决策

| # | 决策 | 说明 |
|---|------|------|
| A1 | 手机唯一入口 | Android APK 经 Tailscale 访问电脑服务端；无桌面窗口、无浏览器 |
| A2 | 电脑端 = 极简托盘程序 | 右键菜单：状态/开机自启/重启/退出；无 Electron |
| A3 | 删码方式：删产品层保底座 | v1 完整代码在 tag `archive/v1`；底座=server 骨架/llmOpenai/APK 构建链/tray.png |
| A4 | PC 更新全自动 | agent（OpenCode）编码+构建+部署→托盘自动重启加载新版；用户不碰电脑 |
| A5 | 旧数据不迁移 | v1 库只读保留；旧书迁移另开 session |
| A6 | 版本号 v3.0.0 起 | semver 与 v1 的 2.2.0 断代；产品名 v2 |
| A7 | 模型统一 OpenAI 协议 | 砍 Anthropic；DeepSeek+GLM 预设填 Key 即用 + 自定义槽位（任意兼容端点含本地） |
| A8 | 模型路由四槽简 UI | 架构按导演/正文/评审/工具四角色留槽，默认全同主模型；UI 简单模式只露主模型+轻量模型 |
| A9 | 无道德审查 | 应用层零内容过滤零说教；无尺度字段，全默认最放开直写；自动剥离模型插入的说教/免责；模型端拦截时换表达重试一次再提示换模型 |
| A10 | **无鉴权直连**（2026-11-05 修订，取代原「扫码+密码+token」） | Tailscale 网络本身即信任边界；手机端手输一次地址（默认值预置）即用；无密码/token/二维码 |

## 2. 写作循环（导演循环）

```
现状卡（常驻）→ 走向卡片 → 章级大纲确认 → 场景级分镜确认（可跳过）→ 流式正文 → 自检 → 自动入书 → 本章纪要卡
```

| # | 决策 | 说明 |
|---|------|------|
| W1 | 常驻现状卡 | 写作页顶部常驻：最近章摘要/未闭合冲突/到期伏笔/人物现状/张力提示；纯数据组装零模型成本；断更>7天附全量前情简报 |
| W2 | 走向卡片 | 默认 4 张类型不同（稳妥推进/冒险转折/人物深化/野路子），agent 按需 1-5 张；字段简化=剧情预告+结构化标注+弧线标注（如「开启 3 章追杀弧」）；带换一批+自由输入 |
| W3 | 两级大纲 | 每章确认章级大纲→场景级分镜（3-6幕，可拖动排序/删幕/批注/换视角/改节奏）；分镜页有「直接开写」逃生门 |
| W4 | 写完自动入书 | 自检过即入书（无状态机无定稿步）；纪要卡展示变更清单可撤销 |
| W5 | 写完停手 | agent 不自动续写；用户点「继续」才出下一轮卡片 |
| W6 | 自检先自动修 | 零成本自检（接缝/穿帮/元语言/重复/字数/事实冲突）失败→自动修正重写一次→再不过给选项（接受瑕疵/再试/换方向） |
| W7 | 章末快捷钮 | 重写/局部改/更狠/更柔/加长/缩短；划段+一句话局部改；对话式指令并行保留 |
| W8 | 纯 agent 改 | 正文只读无编辑器；默认整章重写可指定局部 |
| W9 | 改章=章内多版本 | 每次改产生新版本，当前版生效，历史版可回看；目录树不因修订爆炸 |
| W10 | 生成中排队 | 全局同时只跑一个生成任务；生成中的输入进统一队列；阅读不受限 |
| W11 | 主动取消=作废整章 | 需二次确认；意外中断（杀APP/断网/服务重启）无损恢复继续——两者语义不同 |
| W12 | 任务流水线 | 提案→分镜→写作→自检→评审→收尾每步落库；看门狗 10 分钟无事件标卡住可取消 |
| W13 | 中断恢复 | 杀APP/断网/服务端重启，从最后完成步骤继续 |
| W14 | 串行+排队 | 多书同时发起写作：全局串行，新任务自动排队衔接，状态可见 |

## 3. 开书与设定

| # | 决策 | 说明 |
|---|------|------|
| B1 | 开书=agent 分阶段引导 | 3-6 轮选择题→世界观草案→人物草案→书名简介，逐个拍板；末尾加轻骨架确认（终局方向感+前 3 章概要，一页纸），之后纯卡片驱动滚动，不维护卷骨架 |
| B2 | 红线机制 | 开书引导时问雷点/恒定要求（主角不能死/不要NTR），卡片/正文/新线永远避开，随时增删，违者必纠 |
| B3 | 文风 | 开书时定+可贴参考文字；文风卡=名称+样本+风格要点 |
| B4 | 章节字数 | 开书时选，agent 微调 ±20% |
| B5 | 设定 agent 全权维护 | 写作中自动沉淀/更新；用户只浏览/搜索/钉选 |
| B6 | 两层信息防剧透 | 设定卡分「读者已知/作者真相」两层；写作按读者已知措辞；计划揭示章并入作者真相备注 |
| B7 | 引用两级+引用夹 | 钉选（常驻每次都带）+临时带上（仅下一轮）；引用夹胶囊显示已带条数/字数预算；未引用卡 agent 按需检索自动带；预算超限按钉选>临时截断并提示 |
| B8 | 人物活状态 | 位置/身体/情绪/持有物/知道什么/目标/关系；每章收尾自动更新（纪要卡可撤销） |
| B9 | 关系图不做 | 无图视图；图谱数据结构保留供上下文组装/邻居检索 |
| B10 | 跨书只读引用 | agent 可读其他书设定作开书参考；无复用 UI |

## 4. 数据模型

| # | 决策 | 说明 |
|---|------|------|
| D1 | 分叉树 | 任意章后开新线，线名 agent 自动起；设定/人物状态/伏笔各线独立演化（真平行宇宙）；目录平铺+分叉标记+切线；写作永远在激活线尾 |
| D2 | 不分卷 | 章节平铺；滚动分层记忆（最近章细记+远端滚动压缩前情摘要）+伏笔台账+人物活状态 |
| D3 | 不合并 | 纯树结构无 DAG；「搬段落」走 agent 指令重写 |
| D4 | 无真删除 | 一切重来=分叉（旧章保留旁支零代价）；真删除仅删线/删书（二次确认+删除前自动快照当日库） |
| D5 | 无状态机 | 章节/书无状态流转；写完即入书；完结由用户说一声 agent 开始收线（不预定义结局，agent 不主动管理结局） |
| D6 | 书规模 | 长篇 100-500 章，分层记忆自然兼容短篇 |

## 5. Agent 设计

| # | 决策 | 说明 |
|---|------|------|
| G1 | 导演人格 | 短/具体/有态度（可说「我建议第二张」最终听作者）；先结论后理由；非正文回复≤200字 |
| G2 | 主+子双层 | 主线主 agent；子代理只读/隔离上下文/结构化回报/可并行/失败降级不阻断 |
| G3 | 子代理四角色 | 评审员（七维带引文）/连续性检查员/文风漂移+空转审计员（每N章，异常附走向卡片旁）/分支推演员（评估卡片后果）；手动诊断指令（「帮我诊断这章」）保留 |
| G4 | 启发式引擎 | 候选五源：故事义务/角色欲望/节奏曲线/读者问题/野路子；两段式生成（子代理产 8-12 候选→导演按类型不重复筛 4）；打分：紧迫度/新鲜度/情感收益/风险/偏好匹配 |
| G5 | 反模式纪律 | 不开放式提问踢球/选项必有代价/无空选项（「继续」「过渡」）/信息不越读者已知/不自动续写 |
| G6 | SuperAgent 不照搬 | 借三样：任务持久化+断点恢复/异步执行+看门狗/子代理上下文隔离；不学事件驱动/常驻在线/投机预生成 |
| G7 | 上下文装配 | 系统提示→钉选卡→本轮任务包→临时卡→最近章摘要→检索→远端分层摘要；预算引用≤35%历史≤25%检索≤15%，超窗从低优先级砍 |
| G8 | 工具纪律 | 写类工具返回变更摘要；删除/覆盖正文二次确认；单次工具结果 30000 字上限+截断补救指引；工具参数 JSON 坏返回 inputError 引导重试 |
| G9 | 技术性失败自动重试 | 网络 2 次指数退避；429 读 retry-after≤60s；5xx 重试 1 次；连续失败呈现用户 |
| G10 | 语义嵌入一期就带 | 本地 bge-small-zh（v1 资产），懒加载静默降级，关键词+图谱为回退路径 |

## 9. 验收清单（10 项）

1. 手机完整走通写作循环（连接→开书引导→选走向→两级大纲→流式正文→入书→下一章走向）
2. 分叉树：开新线/切线/各线设定独立演化可验证
3. 托盘起停；手机直连（无鉴权）
4. 钉选生效、人物状态随线演化可验证
5. 子代理审读并行出报告（含文风漂移/剧情空转审计）
6. 自检自动修一次再问
7. APK 自更新全链路（检测→下载→安装确认）
8. agent 构建部署后托盘自动重启加载新版
9. 写作中杀 APP/断网无损恢复继续
10. 敏感指令不被应用层拒绝（直写验收：暴力/性/道德灰色等题材直接写、无说教、无元语言、不中断）
